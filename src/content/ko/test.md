## 코드

`이렇게` 인라인 코드를 표시할 수 있습니다.

코드 블록도 만들 수 있습니다:

```python
# 파이썬 코드입니다
def fibonacci(n):
    if n <= 1:
        return n
    return fibonacci(n-1) + fibonacci(n-2)

print(f"Fibonacci(10) = {fibonacci(10)}")
```
